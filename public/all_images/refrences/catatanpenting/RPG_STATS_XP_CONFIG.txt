RPG STATS & XP CONFIGURATION - InTracker
============================================
============================================

=== XP SOURCES ===

1. HABIT COMPLETION:
   - Difficulty 1 = 15 XP
   - Difficulty 2 = 25 XP
   - Difficulty 3 = 40 XP

2. JOURNALING:
   - Per entry (min 20 chars) = 30 XP
   - Max 5 entries/day = 150 XP max

3. FEED INTERACTION:
   - Post/Comment = 10 XP
   - Max 20 interactions/day = 200 XP max

4. TO-DO COMPLETION:
   - Per task = 10 XP
   - No stat gains, XP only

5. DAILY XP CAP: 1000 XP/day

=== LEVEL CURVE ===
Formula: XP needed = 100 + (level^2 * 1.5)
- Level 1→2: 102 XP
- Level 5→6: 138 XP
- Level 10→11: 250 XP
- Level 20→21: 700 XP
- Level 30→31: 1450 XP
- Level 50→51: 3850 XP
- Level 100: ~15,100 XP needed
- Max Level: 100

Day 90 target (~500 XP/day): Level 28-32
